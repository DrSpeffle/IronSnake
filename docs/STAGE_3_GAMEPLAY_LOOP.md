# IronSnake Stage 3 — Gameplay Loop

Stage 3 converts IronSnake from a tracker into a lightweight behavioural RPG.

## Completed Systems

- Daily Quest Engine
- Cooking Mission Chain
- Fitness Mission Chain
- Strength Mission Chain
- Mind Mission Chain
- Soul Mission Chain
- XP rewards
- Stat rewards
- Daily completion locking
- Evolution rank
- Recovery state
- Dynamic Snake dialogue
- Achievement badges
- Unlock events
- Action log
- Save export
- Save import
- Persistent local state

## Gameplay Loop

1. User opens app.
2. Character state is shown.
3. Snake gives current-state dialogue.
4. User completes daily quests or mission-chain actions.
5. Stats increase.
6. XP increases.
7. Level updates.
8. Badges unlock.
9. Evolution rank changes.
10. Portrait tier changes when assets exist.
11. Progress persists locally.
12. Missed behaviour can trigger daily decay.

## Stage 3 Boundary

Stage 3 remains offline, lightweight, browser-based and mobile-first.

No backend.
No GPS yet.
No AI companion yet.
No account system yet.

Those belong to later stages.
